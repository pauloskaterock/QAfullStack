## 📌 Sobre o Projeto

Este repositório reúne uma coleção completa de projetos de **Automação de Testes (QA Automation)** desenvolvidos em **Ruby**. O objetivo é demonstrar expertise em testes end-to-end, desde a camada de interface do usuário (UI) até APIs e serviços backend, consolidando uma abordagem **fullstack** de qualidade de software.

## 🚀 Tecnologias e Ferramentas

| Categoria | Tecnologias |
|-----------|-------------|
| **Linguagem** | Ruby 3.x |
| **Testes Unitários** | RSpec, Minitest |
| **BDD** | Cucumber, Gherkin |
| **Automação Web** | Capybara, Selenium WebDriver, SitePrism |
| **Automação de API** | HTTParty, RestClient, JSON Schema |
| **Testes Mobile** | Appium, Calabash |
| **Banco de Dados** | Database Cleaner, Factory Bot |
| **Relatórios** | Allure, Report Builder |
| **CI/CD** | GitHub Actions, Jenkins |
| **Versionamento** | Git, GitHub |
